2026/3/24

变分原理

微积分教会我们求极值：给定函数 f(x)f(x)f(x)，令导数为零 f′(x)=0f'(x) = 0f′(x)=0，再用二阶导数分辨极大与极小，就能挑出最优的那个点。这套程序无处不在——利润最大的产量、误差最小的拟合直线、能耗最低的运行方案。但物理与化学中还有一大类"最优"问题，自变量根本不是一个数，而是整条曲线、整个曲面，甚至整个波函数：光沿哪条路径传播用时最短？珠子沿哪条曲线下滑最快？电子处在哪个波函数时能量最低？

这类问题的共同结构是"函数的函数"：输入一个函数，输出一个数。这样的映射叫泛函，研究泛函极值的学问叫变分法。它把"令导数为零"升级为"令变分为零"，用一套语言统一回答上面所有问题——最短路径、最速降线、最小作用量、量子力学基态，全是同一个方程的不同化身。

量子化学系列里，"变分"是出现频率最高的词之一：《变分原理与试探波函数》用它构造近似波函数，《Hartree–Fock 的变分推导》用它导出 HF 方程。本文把背后的数学一次讲清：先建立泛函与变分的直觉，推出欧拉–拉格朗日方程，用两个经典例子练手，再处理带约束的情形与瑞利商，最后回到量子化学。

泛函：函数的函数

其实你早已见过泛函，只是没叫它这个名字。一条曲线 y(x)y(x)y(x) 的弧长

S[y]=∫x1x21+y′2 dxS[y] = \int_{x_1}^{x_2} \sqrt{1 + y'^2}\, \mathrm{d}x S[y]=∫x1​x2​​1+y′2​dx

输入整条曲线，输出一个数——长度。曲线稍微抬一点，长度跟着变一点。再如曲线下方的面积 ∫x1x2y(x) dx\int_{x_1}^{x_2} y(x)\, \mathrm{d}x∫x1​x2​​y(x)dx、旋转曲面的面积、闭合曲线围出的面积，都是"吃进一个函数，吐出一个数"的机器。

定义
设 A\mathcal{A}A 是某个允许的函数集合，例如区间 [x1,x2][x_1, x_2][x1​,x2​] 上足够光滑、端点取定值的全部函数 y(x)y(x)y(x)。若按某个规则给每个 y∈Ay \in \mathcal{A}y∈A 指定一个实数 J[y]J[y]J[y]，就称 JJJ 是 A\mathcal{A}A 上的一个泛函。方括号记号 J[y]J[y]J[y] 提醒我们：自变量是整个函数，而非函数在某一点的取值。

直观理解
函数 f(x)f(x)f(x) 是"数变数"的机器，泛函 J[y]J[y]J[y] 是"函数变数"的机器。给它喂不同的曲线，它吐出不同的数；泛函极值问题就是问：哪条曲线让吐出的数最小（或最大）？

于是极值问题换了提法：不是"哪个 xxx 让 fff 最小"，而是"哪条 yyy 让 JJJ 最小"。要模仿"令导数为零"，先得给函数的"导数"起个名字——这就是变分。

变分与极值条件

给 y(x)y(x)y(x) 加一个小扰动：yε(x)=y(x)+ε η(x)y_\varepsilon(x) = y(x) + \varepsilon\, \eta(x)yε​(x)=y(x)+εη(x)，其中 η(x)\eta(x)η(x) 在端点处为零（保证扰动后的曲线仍是"合法"的），ε\varepsilonε 是小参数。函数形状的改变量 δy=ε η(x)\delta y = \varepsilon\, \eta(x)δy=εη(x) 称为 yyy 的变分，它正是"微分"在函数空间里的对应物。固定 yyy 与 η\etaη，泛函就退化成参数 ε\varepsilonε 的普通一元函数：

Φ(ε)=J[y+εη]\Phi(\varepsilon) = J[y + \varepsilon \eta] Φ(ε)=J[y+εη]

它的一阶变化量记作 δJ=ε Φ′(0)\delta J = \varepsilon\, \Phi'(0)δJ=εΦ′(0)。仿照一元函数在极值点导数为零，得到泛函极值的必要条件。

定义
若 JJJ 在 yyy 处取极值，则对一切满足端点条件的扰动 η\etaη 都有 δJ=0\delta J = 0δJ=0，即 Φ′(0)=0\Phi'(0) = 0Φ′(0)=0。一句话：一阶变分为零是泛函极值的必要条件。

类比
把 J[y]J[y]J[y] 想成一片山谷地形，只是"横坐标"换成了"整条曲线"。驻点处无论把曲线往哪个方向挪（一阶近似下），高度都不变——这与 f′(x)=0f'(x) = 0f′(x)=0 的几何图像一模一样，只不过方向有无穷多个。

常见误区
δJ=0\delta J = 0δJ=0 只是必要条件，找到的可能是极小、极大或鞍点。最速降线问题中泛函甚至没有极大值——绕远路的曲线用时可以任意长。变分法通常关心极小值，实际问题加上物理背景后，辨别一般不难。

欧拉–拉格朗日方程

条件 δJ=0\delta J = 0δJ=0 要对"一切扰动"成立，从中可以榨出一个不含 η\etaη 的微分方程。考虑最常用的形式

J[y]=∫x1x2L(x,y,y′) dxJ[y] = \int_{x_1}^{x_2} L(x, y, y')\, \mathrm{d}x J[y]=∫x1​x2​​L(x,y,y′)dx

Φ′(0)=∫x1x2(∂L∂y η+∂L∂y′ η′)dx=0\Phi'(0) = \int_{x_1}^{x_2} \left( \frac{\partial L}{\partial y}\, \eta + \frac{\partial L}{\partial y'}\, \eta' \right) \mathrm{d}x = 0 Φ′(0)=∫x1​x2​​(∂y∂L​η+∂y′∂L​η′)dx=0

第二项带着 η′\eta'η′，不好处理，用分部积分把它转嫁给 η\etaη：

∫x1x2∂L∂y′ η′ dx=[∂L∂y′ η]x1x2−∫x1x2ddx(∂L∂y′)η dx\int_{x_1}^{x_2} \frac{\partial L}{\partial y'}\, \eta'\, \mathrm{d}x = \left[ \frac{\partial L}{\partial y'}\, \eta \right]_{x_1}^{x_2} - \int_{x_1}^{x_2} \frac{\mathrm{d}}{\mathrm{d}x} \left( \frac{\partial L}{\partial y'} \right) \eta\, \mathrm{d}x ∫x1​x2​​∂y′∂L​η′dx=[∂y′∂L​η]x1​x2​​−∫x1​x2​​dxd​(∂y′∂L​)ηdx

端点处 η(x1)=η(x2)=0\eta(x_1) = \eta(x_2) = 0η(x1​)=η(x2​)=0，第一项消失，于是

∫x1x2[∂L∂y−ddx(∂L∂y′)]η dx=0\int_{x_1}^{x_2} \left[ \frac{\partial L}{\partial y} - \frac{\mathrm{d}}{\mathrm{d}x} \left( \frac{\partial L}{\partial y'} \right) \right] \eta\, \mathrm{d}x = 0 ∫x1​x2​​[∂y∂L​−dxd​(∂y′∂L​)]ηdx=0

这要对一切 η\etaη 成立，而方括号是连续函数，唯一可能就是它恒为零。

定义
泛函 J[y]=∫L(x,y,y′) dxJ[y] = \int L(x, y, y')\, \mathrm{d}xJ[y]=∫L(x,y,y′)dx 的极值曲线必满足欧拉–拉格朗日方程

∂L∂y−ddx(∂L∂y′)=0\frac{\partial L}{\partial y} - \frac{\mathrm{d}}{\mathrm{d}x} \left( \frac{\partial L}{\partial y'} \right) = 0 ∂y∂L​−dxd​(∂y′∂L​)=0

这是一个关于 y(x)y(x)y(x) 的二阶常微分方程，两个积分常数由端点条件定出。

至此，泛函极值问题被翻译成微分方程问题：写出 LLL，列方程，求解。还有一个物理上极受欢迎的推论——当 LLL 不显含 xxx 时，存在守恒量（Beltrami 恒等式）

L−y′ ∂L∂y′=constL - y'\, \frac{\partial L}{\partial y'} = \text{const} L−y′∂y′∂L​=const

下一节的摆线正是靠它才解得干净利落。

两个经典例子

两点之间，直线最短

弧长泛函的被积函数 L=1+y′2L = \sqrt{1 + y'^2}L=1+y′2​ 不显含 yyy，欧拉–拉格朗日方程化为

ddx(y′1+y′2)=0\frac{\mathrm{d}}{\mathrm{d}x} \left( \frac{y'}{\sqrt{1 + y'^2}} \right) = 0 dxd​(1+y′2​y′​)=0

括号内为常数，于是 y′y'y′ 为常数，yyy 是线性函数——连接两点的极值曲线就是直线。"两点之间线段最短"这个几何常识，在变分法里成了欧拉–拉格朗日方程的第一道练习题。

最速降线：一场公开挑战

1696 年，约翰·伯努利向全欧洲的数学家发出挑战：在竖直平面内取两点 AAA、BBB（BBB 不在 AAA 的正下方），让珠子在重力作用下从 AAA 出发沿曲线无摩擦滑到 BBB，问沿哪条曲线用时最短？直觉的回答是直线——两点间距离确实最短，但距离最短不等于时间最短：一条先陡后缓的曲线让珠子更早获得速度，前半程的"高速度"可以补偿后半程的"绕远路"。费马原理早已在光学里用过同样的戏码：光走的正是用时最短（更准确说，驻定）的路径。

取 yyy 轴竖直向下，珠子从原点静止出发。由能量守恒，滑到深度 yyy 处的速度满足 12mv2=mgy\frac{1}{2} m v^2 = m g y21​mv2=mgy，即 v=2gyv = \sqrt{2gy}v=2gy​。下滑总时间是曲线的泛函：

L−y′ ∂L∂y′=1y(1+y′2)=12aL - y'\, \frac{\partial L}{\partial y'} = \frac{1}{\sqrt{y \left( 1 + y'^2 \right)}} = \frac{1}{\sqrt{2a}} L−y′∂y′∂L​=y(1+y′2)​1​=2a​1​

（常数记作 1/2a1/\sqrt{2a}1/2a​），整理得一阶方程

y(1+y′2)=2ay \left( 1 + y'^2 \right) = 2a y(1+y′2)=2a

它的解写成参数形式最为清爽：

x=a(θ−sin⁡θ),y=a(1−cos⁡θ)x = a \left( \theta - \sin\theta \right), \qquad y = a \left( 1 - \cos\theta \right) x=a(θ−sinθ),y=a(1−cosθ)

这正是摆线——半径 aaa 的圆沿直线滚动时，圆周上一点划出的轨迹。如图 1 所示，摆线在出发后率先俯冲，让珠子尽快提速，随后平缓地滑向终点；直线虽然最短，圆弧次之，用时最短的却是摆线。有趣的是，这条摆线还是"等时曲线"：无论珠子从曲线上哪一点出发，滑到最低点所用的时间都相同，惠更斯据此造过摆钟。

直观理解
最速降线的胜负手在起点附近：先"垂直跳水"换取速度，再借高速走捷径。直线输在起步太保守——前半程速度上不去，时间全耗在慢速爬行上。

带约束的极值：拉格朗日乘子登场

许多变分问题自带约束：曲线长度给定、面积固定，或者像量子力学里那样要求波函数归一化 ∫∣ψ∣2 dx=1\int \lvert\psi\rvert^2\, \mathrm{d}x = 1∫∣ψ∣2dx=1。设要在约束 K[y]=∫g(x,y,y′) dx=cK[y] = \int g(x, y, y')\, \mathrm{d}x = cK[y]=∫g(x,y,y′)dx=c 之下求 J[y]J[y]J[y] 的极值，做法与多元函数的拉格朗日乘子法（《Lagrange待定乘子》）如出一辙：把约束乘上一个待定常数，并入目标泛函

J[y]=J[y]−λ K[y]\mathcal{J}[y] = J[y] - \lambda\, K[y] J[y]=J[y]−λK[y]

再对 J\mathcal{J}J 解无约束的欧拉–拉格朗日方程

∂(L−λg)∂y−ddx(∂(L−λg)∂y′)=0\frac{\partial (L - \lambda g)}{\partial y} - \frac{\mathrm{d}}{\mathrm{d}x} \left( \frac{\partial (L - \lambda g)}{\partial y'} \right) = 0 ∂y∂(L−λg)​−dxd​(∂y′∂(L−λg)​)=0

λ\lambdaλ 连同极值曲线一起，由这组方程与约束条件共同确定。经典的等周问题——周长固定时什么曲线围出的面积最大——答案是圆，就是这套程序的成果；而它最重要的登场舞台在量子力学，稍后就到。

瑞利商：本征值的变分刻画

变分法与本征值问题之间有一座直接的金桥。先看有限维：设 A\mathbf{A}A 是 n×nn \times nn×n 实对称矩阵（复 Hermite 矩阵把转置换成共轭转置即可），定义瑞利商

R(c)=cTAccTcR(\mathbf{c}) = \frac{\mathbf{c}^{\mathsf{T}} \mathbf{A} \mathbf{c}}{\mathbf{c}^{\mathsf{T}} \mathbf{c}} R(c)=cTccTAc​

它是向量 c\mathbf{c}c 的函数——在 Rn\mathbb{R}^nRn 上的一个"有限维泛函"。把 c\mathbf{c}c 按正交归一本征基 {vi}\{\mathbf{v}_i\}{vi​} 展开，c=∑izivi\mathbf{c} = \sum_i z_i \mathbf{v}_ic=∑i​zi​vi​，本征值从小到大记为 λ1≤λ2≤⋯≤λn\lambda_1 \le \lambda_2 \le \dots \le \lambda_nλ1​≤λ2​≤⋯≤λn​，则

等号当且仅当 c\mathbf{c}c 恰为对应的本征向量。于是得到本征值的变分刻画。

直观理解
瑞利商把"求本征值"变成"求最小值"：随手抓一个向量算 RRR，结果必然不小于 λ1\lambda_1λ1​，于是 RRR 给 λ1\lambda_1λ1​ 提供了一个免检的上界；不断调整向量让 RRR 下降，就是在向基态本征向量逼近。

自伴算符上的推广一字不差：把矩阵换成自伴算符 A^\hat AA^，向量换成 Hilbert 空间中的态 ∣ψ⟩\ket{\psi}∣ψ⟩（《态变换与Hilbert空间》），瑞利商变为

在量子化学中的应用

量子力学的变分原理：设 H^\hat HH^ 的本征态与本征值为 ∣ψn⟩\ket{\psi_n}∣ψn​⟩ 与 EnE_nEn​，从小到大排列，E0E_0E0​ 是精确基态能量。任取一个归一化的试探波函数 ∣ψ~⟩\ket{\tilde\psi}∣ψ~​⟩（不必是任何本征态），按本征基展开 ∣ψ~⟩=∑ncn∣ψn⟩\ket{\tilde\psi} = \sum_n c_n \ket{\psi_n}∣ψ~​⟩=∑n​cn​∣ψn​⟩，能量期望值为

E[ψ~]=⟨ψ~∣H^∣ψ~⟩=∑n∣cn∣2En≥E0∑n∣cn∣2=E0E[\tilde\psi] = \langle \tilde\psi \mid \hat H \mid \tilde\psi \rangle = \sum_n \lvert c_n \rvert^2 E_n \ge E_0 \sum_n \lvert c_n \rvert^2 = E_0 E[ψ~​]=⟨ψ~​∣H^∣ψ~​⟩=n∑​∣cn​∣2En​≥E0​n∑​∣cn​∣2=E0​

这正是瑞利商论证的翻版：期望值是全部本征能量的加权平均，不可能低于最低者；等号当且仅当 ∣ψ~⟩\ket{\tilde\psi}∣ψ~​⟩ 就是基态。这就是量子力学变分原理——

应用
无论试探波函数多糟糕，它算出的能量期望值永远是精确基态能量的上界。变分原理把"求基态"翻译成"最小化能量期望值"这个泛函极值问题：构造一族带参数的试探波函数，调参数让能量下降，能量越低，波函数通常越接近真态。如何落地成实用方法，见《变分原理与试探波函数》与《变分原理与试探波函数》。

Hartree–Fock 是变分法：HF 把试探空间限制在单个 Slater 行列式内，在这个缩小的空间里最小化能量期望值。对行列式中的轨道做变分，欧拉–拉格朗日方程给出的正是 Hartree–Fock 方程；归一化约束引入的拉格朗日乘子，正是轨道能量（《Hartree–Fock 的变分推导》《Hartree–Fock 与自洽场（SCF）》）。因为是在子空间里取最小，必有 EHF≥E0E_{\mathrm{HF}} \ge E_0EHF​≥E0​：HF 能量仍是上界，精确能量与 HF 能量之差就是电子相关能。用瑞利商的语言说：允许的空间越大，最小值只会更低——这正是"方法层级"逐级改善能量的变分解释（《计算方法的层级与选择》）。

最小作用量原理与经典轨迹：变分法的摇篮是力学。哈密顿原理断言，体系在时刻 t1t_1t1​ 与 t2t_2t2​ 之间走的真实轨迹 q(t)q(t)q(t) 使作用量泛函

取驻值，即 δS=0\delta S = 0δS=0。对 L=T−VL = T - VL=T−V 应用欧拉–拉格朗日方程，两行就得到牛顿第二定律。分子的经典动力学正是这条原理的舞台：在玻恩–奥本海默势能面上，原子核沿经典轨迹运动，轨迹由作用量的驻值条件支配，分子动力学模拟的力学根基就在这里（《分子动力学（MD）与统计力学》《经典力场与分子动力学算法》）。

常见误区
"最小作用量"是历史留下的名字；严格说哈密顿原理只要求作用量取驻值，某些轨迹上作用量其实是极大或鞍点。量子化学里"变分"一词同样既指求驻点也指求最小——看到它时先问一句：目标泛函是什么，取的是驻值还是下界？

类比
从最速降线到量子基态，剧本从未变过：写下描述"代价"的泛函（时间、作用量、能量期望），令变分为零，得到微分方程（欧拉–拉格朗日方程、HF 方程、本征方程），解之即得"最优的函数"。变分法是这一切的共同语法。

小结

  • 泛函是"函数的函数"：输入整条曲线（或波函数），输出一个数。求泛函极值不走"令导数为零"，而是令一阶变分为零——δJ=0\delta J = 0δJ=0 对一切允许的扰动成立。
  • 对 J[y]=∫L(x,y,y′) dxJ[y] = \int L(x, y, y')\, \mathrm{d}xJ[y]=∫L(x,y,y′)dx，δJ=0\delta J = 0δJ=0 等价于欧拉–拉格朗日方程，泛函极值问题由此化为微分方程问题；LLL 不显含 xxx 时还有 Beltrami 守恒量可用。
  • 最速降线问题的答案是摆线：不是最短路径，却用时最短。"最优"取决于泛函选的是什么——换一个泛函，最优曲线就换一副面孔。
  • 带约束的泛函极值用拉格朗日乘子处理：极值化 J−λKJ - \lambda KJ−λK，乘子由约束条件定出；波函数归一化正是这样进入量子力学的。
  • 瑞利商给出本征值的变分刻画：对称矩阵或自伴算符的最低本征值等于瑞利商的最小值，取等号者是最小本征态；本征方程本身就是带约束变分问题的驻点条件。
  • 量子化学的几根支柱共享这套语言：变分原理保证任何试探波函数的能量期望不低于精确基态能量，HF 是在 Slater 行列式空间内的变分最小化，经典轨迹由作用量驻值原理支配。
