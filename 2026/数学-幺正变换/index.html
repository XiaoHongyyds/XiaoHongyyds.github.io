幺正变换

量子力学把一切都押在概率上：波函数的模方是概率密度，态的归一化是"概率总和为一"的数学表达。于是任何一种"变换"——转动坐标系、平移实验装置、或者仅仅让时间流逝——都面对一条铁律：概率不许丢。变换前后的内积必须分毫不差，归一化必须自动保持。什么样的线性变换能做到这一点？答案构成一个极其优美的家族：幺正变换。

幺正变换是复向量空间里的"旋转"：它可以转动矢量的方向、交换基矢、混合成分，但绝不拉伸、绝不剪切，长度与夹角原封不动。上一篇文章《态变换与Hilbert空间》在讲主动与被动变换时让它匆匆露了一面，本文让它当主角：从"概率不能丢"推出幺正条件，认识它的性质与几何图像，再经指数映射与厄米算符牵手，落到基变换、谱定理与两种绘景，最后看它在量子化学里的四处身影。

当变换遇上概率

Born 规则说：处于态 ∣ψ⟩\ket{\psi}∣ψ⟩ 的体系在测量中得到态 ∣ϕ⟩\ket{\phi}∣ϕ⟩ 的概率是 ∣⟨ϕ∣ψ⟩∣2\lvert \langle \phi \mid \psi \rangle \rvert^2∣⟨ϕ∣ψ⟩∣2，而归一化 ⟨ψ∣ψ⟩=1\langle \psi \mid \psi \rangle = 1⟨ψ∣ψ⟩=1 保证所有概率加起来等于一。概率与正交性全都写在内积里，内积是量子力学的万能尺。

现在设一个线性算符 UUU 把态变过去：∣ψ⟩↦U∣ψ⟩\ket{\psi} \mapsto U\ket{\psi}∣ψ⟩↦U∣ψ⟩。要让这套概率解释照常工作，一切内积都必须被保住：

⟨Uϕ∣Uψ⟩=⟨ϕ∣ψ⟩\langle U\phi \mid U\psi \rangle = \langle \phi \mid \psi \rangle ⟨Uϕ∣Uψ⟩=⟨ϕ∣ψ⟩

左边等于 ⟨ϕ∣U†U∣ψ⟩\langle \phi \mid U^{\dagger} U \mid \psi \rangle⟨ϕ∣U†U∣ψ⟩。要求它对一切 ∣ϕ⟩\ket{\phi}∣ϕ⟩、∣ψ⟩\ket{\psi}∣ψ⟩ 成立，只能有 U†U=IU^{\dagger} U = IU†U=I；在有限维中方阵的左逆必是右逆，于是 UU†=IU U^{\dagger} = IUU†=I 也自动成立。（只要求保范数其实也够：极化恒等式能从范数恢复内积，但直接要求保内积最省事。）

直观理解
内积决定概率、期望值与正交性，是全部可观测内容的源头。保住内积，就保住了全部物理；幺正变换就是"不破坏任何物理的变换"。

幺正矩阵：复世界的旋转

定义
方阵 UUU 称为幺正矩阵，如果 U†U=IU^{\dagger} U = IU†U=I 且 UU†=IU U^{\dagger} = IUU†=I。等价地说，UUU 可逆，且逆就是共轭转置：U−1=U†U^{-1} = U^{\dagger}U−1=U†。

由定义立刻读出一串性质：

  • 列向量正交归一：(U†U)ij=δij(U^{\dagger} U)_{ij} = \delta_{ij}(U†U)ij​=δij​ 恰好是"第 iii 列与第 jjj 列的内积"，行向量同理。
  • 保范数：∥Uψ∥2=⟨ψ∣U†U∣ψ⟩=∥ψ∥2\lVert U\psi \rVert^2 = \langle \psi \mid U^{\dagger} U \mid \psi \rangle = \lVert \psi \rVert^2∥Uψ∥2=⟨ψ∣U†U∣ψ⟩=∥ψ∥2。
  • 保体积：det⁡(U†)det⁡(U)=∣det⁡U∣2=1\det(U^{\dagger}) \det(U) = \lvert \det U \rvert^2 = 1det(U†)det(U)=∣detU∣2=1，故 ∣det⁡U∣=1\lvert \det U \rvert = 1∣detU∣=1，变换不放大也不缩小体积。
  • 本征值模为一：若 U∣v⟩=λ∣v⟩U\ket{v} = \lambda \ket{v}U∣v⟩=λ∣v⟩，则 ∣λ∣∥v∥=∥Uv∥=∥v∥\lvert \lambda \rvert \lVert v \rVert = \lVert U v \rVert = \lVert v \rVert∣λ∣∥v∥=∥Uv∥=∥v∥，故 λ=eiθ\lambda = e^{i\theta}λ=eiθ 只是相位。
  • 幺正矩阵之积仍幺正，恒等矩阵是单位元，全体 nnn 阶幺正矩阵构成群 U(n)U(n)U(n)。

若 UUU 是实矩阵，则 U†=UTU^{\dagger} = U^{\mathrm{T}}U†=UT，条件退化为 UTU=IU^{\mathrm{T}} U = IUTU=I——这正是线性代数里的正交矩阵：行列式为 +1+1+1 的是旋转，为 −1-1−1 的是旋转加反射。幺正变换是它在复数世界的推广。

常见误区
幺正与厄米是两回事。厄米矩阵满足 A†=AA^{\dagger} = AA†=A，本征值为实数，扮演可观测量；幺正矩阵满足 U†=U−1U^{\dagger} = U^{-1}U†=U−1，本征值为模一的相位，扮演变换。例如 eiθe^{i\theta}eiθ（θ\thetaθ 不取 000 或 π\piπ）幺正但不厄米。二者各司其职：可观测量厄米，对称与演化变换幺正。

指数映射：厄米算符生成幺正变换

矩阵指数按幂级数定义：

eX=I+X+X22!+X33!+⋯e^{X} = I + X + \frac{X^2}{2!} + \frac{X^3}{3!} + \cdots eX=I+X+2!X2​+3!X3​+⋯

一个关键事实是：厄米算符经指数映射生成幺正变换。设 AAA 厄米，令 U=eiAU = e^{iA}U=eiA，则

U†U=e−iA† eiA=e−iA eiA=IU^{\dagger} U = e^{-iA^{\dagger}}\, e^{iA} = e^{-iA}\, e^{iA} = I U†U=e−iA†eiA=e−iAeiA=I

第一个等号来自共轭转置的定义（矩阵的共轭转置等于各项共轭转置再倒序相乘），第二个等号用了 A†=AA^{\dagger} = AA†=A；e−iAe^{-iA}e−iA 与 eiAe^{iA}eiA 都是同一个 AAA 的幂级数，各项互相对易，指数律成立，乘积自然是 III。同理 UU†=IU U^{\dagger} = IUU†=I。

有限维下反方向也成立：任何幺正矩阵都能写成 U=eiAU = e^{iA}U=eiA，其中 AAA 厄米（把 UUU 对角化后本征值都是 eiθke^{i\theta_k}eiθk​，取 AAA 的本征值为 θk\theta_kθk​ 即可）。于是"厄米"与"幺正"通过指数映射一一对应。

类比
复平面上的 eiθe^{i\theta}eiθ 是单位圆上的旋转，θ\thetaθ 是转角；幺正变换 eiAe^{iA}eiA 是它在高维复空间的推广，厄米算符 AAA 扮演"生成元"的角色。

现在看量子力学中最重要的特例。薛定谔方程

iℏddt∣ψ(t)⟩=H^∣ψ(t)⟩i\hbar \frac{\mathrm{d}}{\mathrm{d}t} \ket{\psi(t)} = \hat{H} \ket{\psi(t)} iℏdtd​∣ψ(t)⟩=H^∣ψ(t)⟩

∣ψ(t)⟩=U(t) ∣ψ(0)⟩,U(t)=e−iH^t/ℏ\ket{\psi(t)} = U(t)\, \ket{\psi(0)}, \qquad U(t) = e^{-i\hat{H}t/\hbar} ∣ψ(t)⟩=U(t)∣ψ(0)⟩,U(t)=e−iH^t/ℏ

H^\hat{H}H^ 厄米，所以 U(t)U(t)U(t) 幺正——薛定谔演化天生保概率，这正是"幺正 = 保内积"的直接兑现。演化还满足群性质 U(t1)U(t2)=U(t1+t2)U(t_1) U(t_2) = U(t_1 + t_2)U(t1​)U(t2​)=U(t1​+t2​)：先演化十分钟再演化五分钟，等于一次演化十五分钟。

更普遍地，数学上有 Stone 定理：任何连续的单参数幺正变换群必有厄米生成元。物理里这组对应闪闪发光：时间平移的生成元是能量，空间平移的生成元是动量，空间转动的生成元是角动量——每个守恒量都是某个连续对称变换的生成元。

直观理解
把幺正演化想成态矢量在单位球面上"散步"：每一步都不改变长度，只改变方向。生成元 H^\hat{H}H^ 决定往哪个方向走、走多快。

基变换与相似变换

《态变换与Hilbert空间》讲过被动变换：态不动，换一组基去看它。设幺正矩阵 UUU 联系新旧基，态的坐标按 c′=U†cc' = U^{\dagger} cc′=U†c 变换，则算符 AAA 的矩阵必须按

常见误区
换基公式 A′=U†AUA' = U^{\dagger} A UA′=U†AU 里的 UUU 究竟是"旧基到新基"还是"新基到旧基"，各书约定不一，有的教材写成 A′=UAU†A' = U A U^{\dagger}A′=UAU†。两种写法都自洽，只是 UUU 的含义正好相反；动手计算前先查清矩阵元 UijU_{ij}Uij​ 的定义，是避免"差一个逆"的唯一办法。

薛定谔绘景与海森堡绘景

期望值里的幺正演化因子可以左右搬动：

⟨ψ(t)∣A∣ψ(t)⟩=⟨ψ(0)∣U†(t) A U(t)∣ψ(0)⟩\langle \psi(t) \mid A \mid \psi(t) \rangle = \langle \psi(0) \mid U^{\dagger}(t)\, A\, U(t) \mid \psi(0) \rangle ⟨ψ(t)∣A∣ψ(t)⟩=⟨ψ(0)∣U†(t)AU(t)∣ψ(0)⟩

等号两边是同一件事的两种记账方式。左边让态随时间流动、算符纹丝不动，这是薛定谔绘景；右边把态冻结在初始时刻，让时间跑进算符里，定义

AH(t)=U†(t) A U(t)A_H(t) = U^{\dagger}(t)\, A\, U(t) AH​(t)=U†(t)AU(t)

这是海森堡绘景。AH(t)A_H(t)AH​(t) 是 AAA 的幺正相似变换，厄米性与本征值都原样保留，仍是合法的可观测量。两种绘景给出完全相同的期望值、相同的概率、相同的物理——它们不是两套理论，而是同一理论的两种坐标选择。

两种绘景不可混用。既然算符已带上时间依赖，就不能再把态写成 ∣ψ(t)⟩\ket{\psi(t)}∣ψ(t)⟩；初学者常犯的错误是让态和算符一起动，结果把物理量算错。动笔前先声明绘景，然后一以贯之。

在量子化学中的应用

时间演化与守恒量：薛定谔绘景中算符 AAA 固定，期望值的时间导数为

ddt⟨A⟩=iℏ⟨[H^,A]⟩\frac{\mathrm{d}}{\mathrm{d}t} \langle A \rangle = \frac{i}{\hbar} \langle [ \hat{H}, A ] \rangle dtd​⟨A⟩=ℏi​⟨[H^,A]⟩

与 H^\hat{H}H^ 对易的可观测量是守恒量。定态是最简单的例子：当 H^∣ψn⟩=En∣ψn⟩\hat{H}\ket{\psi_n} = E_n \ket{\psi_n}H^∣ψn​⟩=En​∣ψn​⟩ 时，演化只是乘一个相位

∣ψn(t)⟩=e−iEnt/ℏ ∣ψn⟩\ket{\psi_n(t)} = e^{-iE_n t/\hbar}\, \ket{\psi_n} ∣ψn​(t)⟩=e−iEn​t/ℏ∣ψn​⟩

幺正演化对本征态只转动相位，一切概率分布纹丝不动——"定态"之名由此而来（《算符理论与本征方程》）。

表象变换：位置表象与动量表象由傅里叶变换连接：

⟨p∣ψ⟩=12πℏ∫e−ipx/ℏ ψ(x) dx\langle p \mid \psi \rangle = \frac{1}{\sqrt{2\pi\hbar}} \int e^{-ipx/\hbar}\, \psi(x)\, \mathrm{d}x ⟨p∣ψ⟩=2πℏ​1​∫e−ipx/ℏψ(x)dx

核 (2πℏ)−1/2e−ipx/ℏ(2\pi\hbar)^{-1/2} e^{-ipx/\hbar}(2πℏ)−1/2e−ipx/ℏ 正是基矢重叠 ⟨p∣x⟩\langle p \mid x \rangle⟨p∣x⟩，整个变换就是从位置基到动量基的幺正基变换：它保住 L2L^2L2 范数（Parseval–Plancherel 定理），所以在两个表象里算出的概率完全一致。幺正性不是傅里叶变换的附加性质，而是"换表象"的身份证（《傅里叶变换、偏微分方程与边界条件》）。

对称操作与群论：分子的旋转、反映等对称操作作用在波函数上，天然是幺正算符；若操作是分子的对称性，它还与 H^\hat{H}H^ 对易。于是 H^\hat{H}H^ 可以与全部对称操作同时对角化，态矢量按不可约表示分类——这就是用群论给分子轨道贴标签、推选择定则的数学基础：跃迁矩 ⟨ψf∣μ^∣ψi⟩\langle \psi_f \mid \hat{\mu} \mid \psi_i \rangle⟨ψf​∣μ^​∣ψi​⟩ 是否为零，由相关不可约表示的直积是否包含全对称表示决定。把哈密顿矩阵按对称性块对角化，本质上就是做一次幺正相似变换（《对称性、群论与选择定则》）。

正交归一在幺正旋转下自动保持。这不是巧合而是设计：SCF 的每一步——Fock 矩阵的 Jacobi 对角化、重叠矩阵的对称正交化——都是对矩阵做幺正或相似变换。占据轨道之间的旋转不改变 Slater 行列式（至多差一个整体相位），占据与虚轨道之间的旋转才真正改变波函数，稳定性分析正是在后一类旋转上做文章；轨道定域化则是在占据空间内寻找一组幺正旋转，让轨道"看起来最像化学键"（《SCF 收敛、失败与诊断》）。

应用
阅读量化程序的文档或输出时，遇到 diagonalization、orbital rotation、localization、symmetry adaptation，都可以翻译成同一句话：找一个合适的幺正变换，把问题的矩阵变成最容易看的形式。幺正性保证翻来转去，能量与概率不变。

小结

  • 幺正变换是保内积的线性变换，U†U=UU†=IU^{\dagger} U = U U^{\dagger} = IU†U=UU†=I；它是复向量空间中的"旋转"，实数特例是正交矩阵，保内积、保范数、保体积。
  • 本征值是模一的相位，行列式模为一，幺正矩阵在乘法下构成群 U(n)U(n)U(n)；幺正与厄米各司其职——变换幺正，可观测量厄米。
  • 厄米算符经指数映射 U=eiAU = e^{iA}U=eiA 生成幺正变换；薛定谔演化 U(t)=e−iH^t/ℏU(t) = e^{-i\hat{H}t/\hbar}U(t)=e−iH^t/ℏ 是最重要的特例，生成元是哈密顿算符。
  • 换基是相似变换 A′=U†AUA' = U^{\dagger} A UA′=U†AU，本征值不变；谱定理保证厄米矩阵总可被幺正变换对角化，这是"物理与表象无关"与变分法共同的根基。
  • 薛定谔绘景让态流动，海森堡绘景让算符流动，幺正性保证二者给出相同的期望值与物理，选哪个只是记账偏好。
  • 时间演化与守恒量、位置/动量表象间的傅里叶变换、对称性分析与 SCF 轨道旋转，都是幺正变换在量子化学中的日常化身。
